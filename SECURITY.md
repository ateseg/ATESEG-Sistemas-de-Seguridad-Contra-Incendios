# Política de seguridad — ATESEG

## Versiones compatibles

| Versión | Soporte de seguridad |
|---|---|
| Rama `main` (versión actual) | Sí |
| Versiones anteriores | No garantizado |

Los cambios de seguridad se aplicarán a la versión actual del proyecto.

## Cómo reportar una vulnerabilidad

Si encuentras un posible fallo de seguridad, no publiques detalles sensibles en una incidencia pública.

Utiliza la opción privada «Report a vulnerability» de GitHub, si está habilitada en este repositorio. Si no está disponible, contacta de forma privada con el responsable del proyecto mediante el canal de contacto oficial de ATESEG.

Incluye una descripción del problema, la página o archivo afectado, los pasos para reproducirlo y su posible impacto. No incluyas contraseñas, tokens ni datos personales.

## Compromiso de respuesta

Revisaremos los reportes recibidos y, si se confirma una vulnerabilidad, evaluaremos las medidas necesarias para corregirla.

## Uso responsable

Realiza pruebas únicamente en sistemas propios o para los que tengas autorización.
